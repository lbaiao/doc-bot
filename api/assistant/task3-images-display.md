# Task 3: Display Extracted Images in Chat List sidebar

Implement a pop-up/modal component, displaying the extracted images from the documents extracted from a given chat.

For each chat button in the chat list sidebar, add an onClick event that opens a pop-up/modal component. This component will display miniatures of the extracted images from the documents associated with that chat.

The feature will help the user make sure the app extracted images correctly out of the corresponding documents.

This feature will require changes to both frontend and backend.
